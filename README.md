# Syed Hamza — Resume OS

Interactive Executive Resume & Portfolio for Syed Hamza, Electronics & Communication Engineer specializing in AI Integration and Full-Stack Web Development.

## 🚀 Features

- **Executive Resume System**: Interactive tabs for Experience, Projects, Skills, Education, and Certifications.
- **Modern UI/UX**: Dark mode aesthetic, micro-animations, glassmorphism, responsive mobile header & navigation pill strip.
- **Skills Deep Dive**: Comprehensive breakdown of core competencies, frameworks, and tools.
- **Print Optimization**: Dedicated print styling for crisp PDF exports.

## 🛠️ Tech Stack

- HTML5 / CSS3 / JavaScript (Vanilla)
- Google Fonts: Plus Jakarta Sans, Inter, JetBrains Mono
- Zero-dependency local Node.js static server

## 💻 Running Locally

To run locally with Node.js:
```bash
node server.js
```
Then open [http://localhost:3001](http://localhost:3001) (or your Wi-Fi IP address shown in terminal) in your browser.
